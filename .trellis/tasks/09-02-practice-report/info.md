# 实践报告文档设计

## 目标、用户与成功标准

- 用户：计算机科学与技术专业学生。
- 目标：在桌面生成结构完整、正文不少于 3000 字、可编辑和可打印的 Word 课程报告草稿。
- 成功标准：内容围绕大学生生成式人工智能应用，方法和来源可核验，排版符合 A4 常规课程报告要求，鉴定页只预留真实签字盖章区域。
- 明确不做：不虚构问卷、访谈、观察、统计比例、实践单位评价、负责人签名或公章。

## Source of Truth

- 学校要求：用户提供的“社会调查与实践课程安排”截图。
- 用户输入：专业为计算机科学与技术；主题为大学生生成式人工智能应用；没有问卷和其他已完成调查。
- 政策与规范：教育部、国家互联网信息办公室等官方公开文件，以及 UNESCO 已公开出版物。
- 文档身份字段：用户本人填写，生成程序不猜测。
- 单位鉴定与公章：实践单位是唯一权威来源，文档仅提供空白表格。

## 文档边界

1. 内容模块：摘要、背景、方法、场景分析、风险、原因、建议和反思。
2. 来源模块：参考资料逐条列出机构、题名、年份和链接，不引用未核验统计数字。
3. 版式模块：A4、宋体正文、黑体标题、固定页边距、1.5 倍行距、页码和规范表格。
4. 附件模块：资料检索记录、可选访谈提纲、照片粘贴位，明确区分现有材料与待补材料。
5. 鉴定模块：单位意见、负责人签字、日期和盖章空白区，不嵌入印章图片。

## 数据流

学校要求与用户事实 -> 公开来源核验 -> 结构化报告内容 -> DOCX 生成 -> 文本与容器验证 -> 桌面交付。

## 输出契约

- 文件：C:\Users\Lenovo\Desktop\大学生生成式人工智能应用社会实践报告.docx
- 格式：Office Open XML Word 文档，A4 纵向。
- 正文：不少于 3000 个汉字，不以封面、目录、参考资料和空白表格凑字数。
- 可编辑字段：姓名、学号、学校、班级、实践单位、实践日期。
- 错误处理：若 DOCX 无法生成、无法重新打开或正文不足 3000 字，任务不得宣称完成。

## 风险与验证

- 真实性风险：明确方法边界，禁止把公开资料分析写成问卷或实地调查。
- 官方证明风险：不生成公章；鉴定内容由真实单位填写。
- 兼容风险：用 python-docx 生成并重新读取，检查 ZIP 容器。
- 质量检查：统计正文汉字数，检查必需章节、参考来源、空白鉴定页和图片数量。
- 残余风险：学校若强制要求问卷、访谈或实践照片，本草稿不能替代这些真实材料。
