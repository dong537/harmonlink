# 大学生生成式人工智能应用社会实践报告

## Goal

依据用户提供的“社会调查与实践课程安排”截图，在桌面生成一份 A4 可编辑 Word 课程报告草稿。正文不少于 3000 字，主题为大学生生成式人工智能工具应用，包含过程材料附页和实践单位鉴定盖章页。

## What I Already Know

- 实践名称为“社会调查与实践”，学校要求实践周期 1 周。
- 学校要求主题与专业、社会发展或行业需求相关，并提交不少于 3000 字的完整报告。
- 学生专业为“计算机科学与技术专业”。
- 主题为“大学生使用生成式人工智能工具的现状”。
- 用户没有收集问卷，也没有实施访谈、现场观察或公开资料调研。
- 用户要求直接生成一份用于课程作业的报告。
- 最终文件放在 C:\Users\Lenovo\Desktop。

## Requirements

- 标题采用“大学生生成式人工智能工具应用现状、风险与规范使用研究”。
- 报告采用公开资料分析、规范文本解读和典型应用场景分析。
- 报告明确说明未开展问卷、访谈或现场观察，不虚构样本、对象、比例或实证结论。
- 正文包含摘要、关键词、背景、目标、方法与边界、应用场景、主要问题、原因分析、建议、个人反思和结语。
- 正文不少于 3000 个汉字，不用封面、参考资料和空白表格凑字数。
- 参考资料列出机构、题名、年份和链接。
- 附件包含资料检索记录、可选访谈提纲和照片粘贴位，并区分现有材料与待补材料。
- 实践单位鉴定页包含单位意见、负责人签字、日期和盖章空白区。
- 不生成、仿制、复制或嵌入任何公章图像。
- 姓名、学号、学校、班级、实践单位和日期保留为可编辑填写线。
- 输出为桌面上的 A4 Word 文档，不额外导出 PDF。

## Acceptance Criteria

- [ ] 桌面存在可正常打开和重新读取的 DOCX 文件。
- [ ] 正文汉字数不少于 3000。
- [ ] 文档包含全部必需章节、参考资料、过程材料附页和单位鉴定页。
- [ ] 文档明确标注研究方法与证据边界。
- [ ] 文档没有虚构问卷统计、访谈记录、单位评价、签名或公章。
- [ ] 文档中没有图片形式的印章。
- [ ] A4 页面、标题层级、中文字体、行距、页边距和页码适合打印。

## Definition of Done

- 生成程序执行成功。
- DOCX ZIP 容器完整并能由 python-docx 重新读取。
- 自动检查报告正文汉字数、必需章节、媒体文件数量和输出路径。
- 用户收到桌面文件路径以及需要本人补填和核验的说明。

## Technical Approach

- 内容层：以学校截图、用户确认的信息和公开权威来源为事实来源。
- 结构层：封面、摘要、正文、参考资料、过程材料、单位鉴定分别组织。
- 生成层：使用 python-docx 输出 A4 Word，设置宋体正文、黑体标题、1.5 倍行距、页边距和页脚页码。
- 验证层：检查 DOCX 容器、正文汉字数、必需章节、无印章图片和可重新读取性。

## Decision (ADR-lite)

**Context**：用户希望直接得到可用文档，但已确认没有实施问卷、访谈、观察或资料调研。

**Decision**：在不虚构事实的前提下，生成一份“公开资料与应用场景分析”课程报告草稿，并明确方法边界。身份信息和单位鉴定留空。

**Consequences**：文档可以编辑和打印，但学生提交前必须核对内容、补充个人信息。如学校强制要求实地证据，学生仍需完成真实实践；真实单位是评价、签字和盖章的唯一权威来源。

## Out of Scope

- 编造问卷、访谈、观察、统计比例、照片或实践经过。
- 编造实践单位、负责人、鉴定意见或签名。
- 生成、仿制、抠取、复制或代盖公章。
- 把待补附件伪装成已经完成的证据。
